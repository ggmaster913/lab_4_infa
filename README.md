# Лабораторная работа №4 — ленивые последовательности и ординалы

Вариант 2: «Алгебра ленивых списков и алгебра ординальных чисел».
Продолжение ЛР-2: база лежит в `include/lab2/` без изменений.

## Что реализовано

| Пункт методички | Что это | Файл |
|---|---|---|
| АТД LazySequence | ленивая последовательность с мемоизацией, длина — ординал | `include/LazySequence.h` |
| Generator | интерфейс `IGenerator` (`GetNext`, `HasNext`, `TryGetNext`), генератор из массива и по рекуррентному правилу | `include/Generator.h` |
| Операции над ленивыми списками | генераторы склейки, пропуска, взятия, `Map`, `Where` | `include/OperationGenerators.h` |
| Тип длины | ординалы ω·a + b: сложение, сравнение | `include/Ordinal.h` |
| Optional | `Option<T>` для `TryGetNext` | `include/Option.h` |
| Семейство Stream | потоки чтения из `Sequence` и `LazySequence`, поток записи в `Sequence` | `include/Stream.h` |
| Потоки файла | чтение из файла по строке (файл не грузится целиком) и запись в файл | `include/FileStream.h` |
| Тематическая задача | законы моноида ленивых списков и сложение длин | `include/LazyAlgebra.h` |

### Основные решения

- Длина хранится как ординал ω·a + b. `Append` к бесконечной даёт ω+1, `Prepend` — ω, склейка двух бесконечных — ω·2.
- ω — граница: `Get(int)` до неё не доходит, `Get(Ordinal)` с бесконечным индексом бросает исключение.
- Операции не вычисляют элементов: они собирают новый генератор из копий генераторов источника. Исходную последовательность после операции можно удалять.
- `LazySequence` не наследует `Sequence`: иначе длина обязана быть `int`, а `Get` — `const`.
- Правила и функции передаются указателями на функции, без `std::function`.
- Кэш растёт вдвое, решение о росте принимает `LazySequence`, `DynamicArray::Resize` меняет размер ровно до запрошенного.
- Поток записи не владеет целью и отказывается писать в неизменяемую последовательность, поэтому утечки нет.
- Файл читается по одной строке с упреждением на строку вперёд, поэтому подходит и для больших файлов. `Seek` у файла не поддерживается.
- `InsertAt` умеет вставлять и элемент, и целую (в том числе бесконечную) последовательность.

Некорректные аргументы и обращения за границу бросают `std::invalid_argument` или `std::out_of_range`.

include/

## Сборка

Нужны CMake 3.14 или новее и компилятор с поддержкой C++17.
GoogleTest скачивается автоматически при первой настройке.

```bash
cmake -S . -B build
cmake --build build
```

## Тесты

```bash
./build/tests
```

76 тестов: 24 на базу ЛР-2, 35 на ординалы, `Option`, генераторы, ленивые последовательности и законы моноида, 12 на потоки (в том числе файловые), 5 на миллионы элементов.

## Консольное меню

```bash
./build/ui
```

1. Создать последовательность — ввод с клавиатуры, случайные числа, арифметическая прогрессия, Фибоначчи, степени двойки, готовые наборы.
2. Показать последовательность — длина, первые элементы, сколько посчитано.
3. Операции — `Get`, `Get` по ординалу, `GetFirst`/`GetLast`, `Reduce`, `Append`, `Prepend`, `InsertAt`, `Concat`, `GetSubSequence`, `Map`, `Where`, вставка последовательности из другого слота.
4. Законы моноида — ассоциативность, нейтральный элемент, коммутативность, сложение длин.
5. Потоки — чтение с `Seek`, запись с клавиатуры в список, запись слота в файл, чтение файла в новый слот.
6. Автоматический прогон законов на случайных и бесконечных последовательностях с параметрами.
7. Предельные значения — N элементов (до 3 000 000) через `Get`, `Map`/`Reduce`, потоки и файл, с замером времени.
8. Удалить последовательность.
